BALLOTRIXS CANDIDATE IMAGES

Put candidate images in this folder (or one of the year folders):

public/candidates/2026/
public/candidates/2025/
public/candidates/2024/
public/candidates/2023/

Supported formats: JPG, JPEG, PNG, WebP.

Examples:
  public/candidates/2026/arjun.jpg
  public/candidates/2026/rahul.png

In the Admin > Candidates screen, enter either:
  arjun.jpg
or:
  2026/arjun.jpg

The application stores only the repository path in the database, for example:
  /candidates/2026/arjun.jpg

When you add/change an image, commit and push the image file so Vercel deploys it.
